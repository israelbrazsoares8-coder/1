Como gerar o APK:
1. Crie um repositório no GitHub e envie todos os arquivos desta pasta, incluindo a pasta .github
2. Abra a aba Actions e aguarde o workflow Compilar APK terminar
3. Entre na execução concluída e baixe BrazLauncher-APK em Artifacts
4. Extraia o ZIP e instale o arquivo app-debug.apk no celular
5. Aperte o botão Home e escolha Braz Launcher como padrão
